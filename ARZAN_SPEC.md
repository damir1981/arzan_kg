## 1. Концепция и видение продукта (Product Vision)

**Arzan.kg** («Арзан» — с кырг. *дешёвый, выгодный*) — ведущий сервис коллективных скидок и электронных купонов в Кыргызстане, созданный по модели американского сервиса **Groupon** (а также аналогов Chocolife, BeSmart, Biglion).

### 1.1. Главная цель
Предоставить жителям и гостям Бишкека, Оша и Иссык-Куля доступ к лучшим заведениям, развлечениям и услугам города со скидками **до 90%**, а местному бизнесу — мощный канал привлечения новых платежеспособных клиентов без предоплаты за рекламу.

### 1.2. Целевая аудитория
1. **Покупатели (B2C)**: Жители городов (студенты, семьи, молодежь), которые ищут выгодный отдых, походы в рестораны, кино, спа, аквапарки или отели.
2. **Партнеры / Заведения (B2B)**: Кафе, рестораны, салоны красоты, стоматологии, развлекательные центры, отели и автомойки, стремящиеся заполнить пустующие посадочные места или часы низкой загрузки.

## 2. Бизнес-модель (Business Model)

1. **Модель купона (Coupon / Discount Voucher)**:
   - Клиент покупает на сайте Arzan.kg электронный купон за символическую сумму (например, **30–100 сом**).
   - При предъявлении купона в заведении клиент получает скидку (например, **-50% на весь счет** или **-60% на меню**).
   - Заведение получает клиента, продает дополнительные позиции и зарабатывает лояльность.
2. **Модель сертификата (Prepaid Deal Voucher)**:
   - Полная предоплата услуги со скидкой (например, абонемент в спа за 2 200 сом вместо 5 500 сом).
3. **Электронный купон (Electronic Ticket)**:
   - Купон генерирует уникальный промокод формата `ARZ-XXXX-KG` и QR-код.
   - Клиент показывает QR-код со смартфона официанту / кассиру / администратору.

## 5. Модель данных (Data Model)

### 5.1. Акция (`Deal`)
```typescript
export interface Deal {
    id: string;                     // Уникальный ID (например, "1")
    title: string;                  // Заголовок акции ("Скидка 50% на меню в чайхане Нават")
    shortDescription: string;       // Краткий подзаголовок для карточки
    description: string;            // Полное описание условий
    category: string;               // "Рестораны и еда", "Развлечения", "Красота и SPA" и др.
    images: string[];               // Массив ссылок на фото
    originalPrice: number;          // Цена без скидки (сом), например: 2000
    discountPrice: number;          // Цена со скидкой (сом), например: 1000
    discountPercent: number;        // Процент скидки, например: 50
    couponPrice: number;            // Стоимость самого купона, например: 50
    currency: 'KGS';                // Валюта (сом)
    boughtCount: number;            // Сколько людей купили акцию ("Куплено 487")
    expiresAt: number;              // Timestamp окончания акции (для таймера)
    location: string;               // Город ("Бишкек", "Ош", "Иссык-Куль")
    merchant: Merchant;             // Информация о заведении-партнере
    features: string[];             // Список «Особенности акции»
    conditions: string[];           // Список «Условия и правила купона»
    badge?: 'Хит' | 'Скидка дня' | '-70%' | '-50%' | 'Эксклюзив' | 'Новинка';
    createdAt: number;
}
```

### 5.2. Партнер / Заведение (`Merchant`)
```typescript
export interface Merchant {
    name: string;                   // Название ("Чайхана «Нават»")
    logo?: string;                  // Логотип заведения
    address: string;                // Точный адрес ("ул. Киевская, 114")
    city: string;                   // "Бишкек"
    phone: string;                  // Телефон бронирования ("+996 555 500-111")
    workingHours: string;           // Режим работы ("Ежедневно: 10:00 — 23:00")
    instagram?: string;             // Ссылка или ник (@navat_kg)
    rating: number;                 // Рейтинг (например: 4.9)
    reviewsCount: number;           // Количество отзывов (например: 320)
}
```

### 5.3. Электронный купон (`Voucher`)
```typescript
export interface Voucher {
    id: string;                     // Уникальный ID купона ("v_171...")
    dealId: string;                 // Ссылка на акцию
    dealTitle: string;              // Название акции
    merchantName: string;           // Заведение
    merchantAddress: string;        // Адрес применения
    merchantPhone: string;          // Телефон для записи
    code: string;                   // Уникальный код купона (например: "ARZ-8942-KG")
    qrCodeUrl?: string;             // QR-код для сканирования на кассе
    discountPercent: number;        // Размер скидки (-50%)
    discountPrice: number;          // Итоговая цена
    purchasedAt: number;            // Дата покупки купона
    expiresAt: number;              // Срок действия
    status: 'active' | 'used' | 'expired';
}
```

## 6. Основные пользовательские сценарии (Key User Flows)

### 6.1. Поиск и покупка купона клиентом
1. **Главная страница**: Клиент просматривает витрину горящих акций, баннер «Скидка дня» с таймером и фильтрует предложения по категориям («Рестораны и еда», «Развлечения», «SPA»).
2. **Карточка акции (`DealCard`)**: Видит процент экономии, реальную экономию в сомах, сколько людей уже купили и рейтинг заведения.
3. **Страница акции (`/product/[id]`)**: Ознакамливается с особенностями меню/услуги, правилами использования купона и контактами заведения.
4. **Покупка купона**: Нажимает «Купить купон за 50 сом». Всплывает модальное окно успешного оформления с промокодом (например, `ARZ-8942-KG`) и QR-кодом.
5. **Кошелек купонов (`/vouchers`)**: Купон сохраняется в разделе «Мои купоны» с билетом и кнопкой копирования для показа в заведении.

### 6.2. Подача акции заведением-партнером (`/upload`)
1. Представитель бизнеса заходит в раздел «Партнерам» / «Бизнесу: разместить акцию».
2. Заполняет данные компании (название, телефон, адрес, город).
3. Вводит обычную цену и желаемую цену со скидкой — система **автоматически вычисляет процент скидки**.
4. Загружает фотографии интерьера, блюд или процедур с мгновенным предпросмотром.
5. Нажимает «Опубликовать акцию на Arzan.kg» — акция мгновенно появляется в каталоге.

1. **Рестораны и еда** (Чайханы, суши-бары, бургерные, пиццерии, кофейни, банкетные залы).

Следующие функции запланированы к внедрению в следующих итерациях:

### Этап 1: Платежные шлюзы Кыргызстана (Fintech Integration)
- [ ] **MBank (Коммерческий банк Кыргызстан)**: Прием оплаты за купоны через MBank QR / API.

- [ ] **Банковские карты (Элкарт, Visa, Mastercard)**.

### Этап 2: Кабинет заведения и сканер купонов (Merchant & Cashier Portal)
- [ ] **Веб-сканер QR-кодов кассира**: Страница `/merchant/scan`, где официант или администратор может навести камеру смартфона на QR-код гостя и за 1 секунду погасить купон (статус меняется на `used`).
- [ ] **Кабинет партнера**: Статистика продаж, сумма привлеченной выручки, аналитика по дням недели.

### Этап 3: Уведомления и социальные механики (Growth & Retention)
- [ ] **Telegram-бот Arzan.kg**: Оповещение пользователей о новых супер-скидках недели и отправка купленных купонов прямо в Telegram.
- [ ] **Отзывы с фото**: Возможность пользователей оставлять честные отзывы после погашения купона.
- [ ] **Таймер реального обратного отсчета (Real-time Countdown)**: Живые секунды и миллисекунды на баннере «Скидка дня».
- [x] **Кыргызский язык (Кыргызча)**: Двуязычный интерфейс (RU / KG).

### Важные правила при внесении изменений:
1. **Стилизация**: Использовать только Tailwind CSS v4 классы. Все импорты находятся в [src/app/globals.css](file:///Users/damirarzy/.gemini/antigravity/scratch/marketplace/src/app/globals.css). Не удалять файл `postcss.config.mjs`.
2. **Отказоустойчивость**: Методы `getAllDeals()` и `getDealById()` в [src/lib/deals.ts](file:///Users/damirarzy/.gemini/antigravity/scratch/marketplace/src/lib/deals.ts) используют race-таймаут к Firestore с гарантированным fallback на локальные/начальные данные. Приложение **никогда не должно падать** при проблемах с сетью.
3. **Изображения**: Внешние хосты картинок (`placehold.co`, `lh3.googleusercontent.com`, `firebasestorage.googleapis.com`) зафиксированы в [next.config.ts](file:///Users/damirarzy/.gemini/antigravity/scratch/marketplace/next.config.ts). При добавлении новых CDN обязательно обновлять `remotePatterns`.
