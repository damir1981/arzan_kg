## 1. Концепция и видение продукта (Product Vision)

**Kupon.kg** — ведущий сервис коллективных скидок и электронных купонов в Кыргызстане, созданный по модели американского сервиса **Groupon** (а также аналогов Chocolife, BeSmart, Biglion).

### 1.1. Главная цель
Предоставить жителям и гостям Бишкека, Оша и Иссык-Куля доступ к лучшим заведениям, развлечениям и услугам города со скидками **до 90%**, а местному бизнесу — мощный канал привлечения новых платежеспособных клиентов без предоплаты за рекламу.

### 1.2. Целевая аудитория
1. **Покупатели (B2C)**: Жители городов (студенты, семьи, молодежь), которые ищут выгодный отдых, походы в рестораны, кино, спа, аквапарки или отели.
2. **Партнеры / Заведения (B2B)**: Кафе, рестораны, салоны красоты, стоматологии, развлекательные центры, отели и автомойки, стремящиеся заполнить пустующие посадочные места или часы низкой загрузки.

## 2. Бизнес-модель (Business Model)

1. **Модель купона (Coupon / Discount Voucher)**:
   - Клиент покупает на сайте Kupon.kg электронный купон за символическую сумму (например, **30–100 сом**).
   - При предъявлении купона в заведении клиент получает скидку (например, **-50% на весь счет** или **-60% на меню**).
   - Заведение получает клиента, продает дополнительные позиции и зарабатывает лояльность.
2. **Модель сертификата (Prepaid Deal Voucher)**:
   - Полная предоплата услуги со скидкой (например, абонемент в спа за 2 200 сом вместо 5 500 сом).
3. **Электронный купон (Electronic Ticket)**:
   - Купон генерирует уникальный промокод формата `KPN-XXXX-KG` и QR-код (либо мгновенно, либо после подтверждения наличия свободных мест бизнесом).
   - Клиент показывает QR-код со смартфона официанту / кассиру / администратору.

## 5. Модель данных (Data Model)

### 5.1. Акция (`Deal`)
```typescript
export interface Deal {
    id: string;                     // Уникальный ID (например, "1")
    title: string;                  // Заголовок акции ("Скидка 50% на меню в чайхане Нават")
    shortDescription: string;       // Краткий подзаголовок для карточки
    description: string;            // Полное описание условий
    category: string;               // "Рестораны и еда", "Развлечения", "Красота и SPA" и др.
    images: string[];               // Массив ссылок на фото
    originalPrice: number;          // Цена без скидки (сом), например: 2000
    discountPrice: number;          // Цена со скидкой (сом), например: 1000
    discountPercent: number;        // Процент скидки, например: 50
    couponPrice: number;            // Стоимость самого купона, например: 50
    currency: 'KGS';                // Валюта (сом)
    boughtCount: number;            // Сколько людей купили акцию ("Куплено 487")
    expiresAt: number;              // Timestamp окончания акции (для таймера)
    location: string;               // Город ("Бишкек", "Ош", "Иссык-Куль")
    merchant: Merchant;             // Информация о заведении-партнере
    features: string[];             // Список «Особенности акции»
    conditions: string[];           // Список «Условия и правила купона»
    badge?: 'Хит' | 'Скидка дня' | '-70%' | '-50%' | 'Эксклюзив' | 'Новинка';
    requiresConfirmation?: boolean; // Требуется ли подтверждение бизнеса (проверка свободных мест) перед выдачей QR-кода
    createdAt: number;
}
```

### 5.2. Партнер / Заведение (`Merchant`)
```typescript
export interface Merchant {
    name: string;                   // Название ("Чайхана «Нават»")
    logo?: string;                  // Логотип заведения
    address: string;                // Точный адрес ("ул. Киевская, 114")
    city: string;                   // "Бишкек"
    phone: string;                  // Телефон бронирования ("+996 555 500-111")
    workingHours: string;           // Режим работы ("Ежедневно: 10:00 — 23:00")
    instagram?: string;             // Ссылка или ник (@navat_kg)
    rating: number;                 // Рейтинг (например: 4.9)
    reviewsCount: number;           // Количество отзывов (например: 320)
}
```

### 5.3. Электронный купон (`Voucher`)
```typescript
export interface Voucher {
    id: string;                     // Уникальный ID купона ("v_171...")
    dealId: string;                 // Ссылка на акцию
    dealTitle: string;              // Название акции
    dealImage: string;              // Обложка акции
    merchantName: string;           // Заведение
    merchantAddress: string;        // Адрес применения
    merchantPhone: string;          // Телефон для записи
    code: string;                   // Уникальный код купона ("KPN-8942-KG" или "PENDING" до одобрения)
    qrCodeUrl?: string;             // QR-код для сканирования на кассе
    discountPercent: number;        // Размер скидки (-50%)
    discountPrice: number;          // Итоговая цена
    couponPrice: number;            // Стоимость купона
    purchasedAt: number;            // Дата покупки / отправки запроса
    expiresAt: number;              // Срок действия
    status: 'pending' | 'active' | 'declined' | 'used' | 'expired';
    customerName?: string;          // Имя клиента (для заявок с подтверждением)
    customerPhone?: string;         // Телефон клиента (для связи с заведением)
    declineReason?: string;         // Причина отказа или кастомное сообщение от бизнеса (например: "На сегодня все места заняты")
    respondedAt?: number;           // Время ответа бизнеса (одобрения или отклонения)
    userNotified?: boolean;         // Показано ли пользователю всплывающее уведомление об ответе бизнеса
}
```

## 6. Основные пользовательские сценарии (Key User Flows)

### 6.1. Поиск и покупка купона клиентом
1. **Главная страница**: Клиент просматривает витрину горящих акций, баннер «Скидка дня» с таймером и фильтрует предложения по категориям («Рестораны и еда», «Развлечения», «SPA»).
2. **Карточка акции (`DealCard`)**: Видит процент экономии, реальную экономию в сомах, сколько людей уже купили, рейтинг заведения и бейдж режима выдачи купона («Мгновенный купон» или «По подтверждению бизнеса»).
3. **Страница акции (`/product/[id]`)**: Ознакамливается с особенностями меню/услуги, правилами использования купона и контактами заведения.
4. **Покупка / Запрос купона**:
   - Если `requiresConfirmation = false`: Нажимает «Купить купон». Мгновенно открывается модальное окно с готовым промокодом (`KPN-XXXX-KG`) и QR-кодом.
   - Если `requiresConfirmation = true`: Вводит имя/телефон и нажимает «Запросить купон». Запрос отправляется владельцу бизнеса (`status: 'pending'`), а QR-код остается заблокированным до подтверждения наличия мест.
5. **Кошелек купонов (`/vouchers`)**: Купон сохраняется в разделе «Мои купоны» с актуальным статусом (`На подтверждении у бизнеса`, `Активен — покажите QR на кассе` или `Отклонено заведением` с текстом причины).

### 6.2. Подача акции заведением-партнером (`/upload`)
1. Представитель бизнеса заходит в раздел «Партнерам» / «Бизнесу: разместить акцию».
2. Заполняет данные компании (название, телефон, адрес, город).
3. Вводит обычную цену и желаемую цену со скидкой — система **автоматически вычисляет процент скидки**.
4. Загружает фотографии интерьера, блюд или процедур с мгновенным предпросмотром.
5. **Выбирает режим выдачи купонов (Toggle «Требуется подтверждение купона бизнесом»)**:
   - **Выключено (`requiresConfirmation: false`)**: Клиенты получают QR-код автоматически сразу после нажатия кнопки.
   - **Включено (`requiresConfirmation: true`)**: Защищает бизнес от овербукинга, когда количество столиков, номеров или мест в SPA ограничено.
6. Нажимает «Опубликовать акцию на Kupon.kg» — акция мгновенно появляется в каталоге.

### 6.3. Система подтверждения купонов бизнесом и контроля свободных мест (`/merchant`)
Эта функция помогает бизнесу и клиентам избежать ситуаций, когда пользователь покупает купон, но в заведении нет свободных мест:
1. **Входящая заявка**: Когда пользователь запрашивает купон по акции с `requiresConfirmation: true`, создается запись `Voucher` со статусом `'pending'` и кодом `'PENDING'`. В верхней панели (`Navbar.tsx`) на кнопке **«Заявки бизнеса» (`/merchant`)** загорается индикатор новых заявок.
2. **Обработка заявки владельцем бизнеса (`/merchant`)**:
   - Бизнес видит карточку клиента (имя, телефон, время запроса, название акции).
   - **Кнопка «Одобрить (выдать QR)» (`approveVoucherRequest`)**: Статус купона меняется на `'active'`, генерируется уникальный код `KPN-XXXX-KG`, разблокируется QR-код, а флаг `userNotified` устанавливается в `false`.
   - **Кнопка «Отклонить» (`declineVoucherRequest`)**: Открывает поле ввода сообщения для клиента с быстрыми шаблонами (*«К сожалению, свободных мест на сегодня нет»*, *«Запись полная, попробуйте на завтра»*) или произвольным комментарием от заведения. Статус меняется на `'declined'`, сохраняется `declineReason`, а флаг `userNotified` устанавливается в `false`.
3. **Всплывающее уведомление клиенту (`Navbar.tsx` + `/vouchers`)**:
   - Как только бизнес отвечает на заявку, у пользователя автоматически всплывает модальное окно уведомления:
     - При **одобрении**: Уведомление «Бизнес подтвердил ваш купон!» с готовым QR-кодом и промокодом `KPN-XXXX-KG`.
     - При **отказе**: Уведомление «Запрос на купон отклонен» с точным сообщением от бизнеса (`declineReason`), объясняющим отсутствие свободных мест или предлагающим другое время.

## 7. Категории акций на Kupon.kg

1. **Рестораны и еда** (Чайханы, суши-бары, бургерные, пиццерии, кофейни, банкетные залы).
2. **Развлечения** (Кинотеатры, аквапарки, боулинг, караоке, VR-арены, квесты).
3. **Красота и SPA** (Тайский массаж, хаммам, стрижки, барбершопы, косметология, ногтевой сервис).
4. **Здоровье** (Стоматологии, чекапы, МРТ, анализы, коррекция зрения).
5. **Туризм и отдых** (Коттеджи на Иссык-Куле, горные туры, базы отдыха, Чон-Кемин, Ала-Арча).
6. **Авто и услуги** (3-фазная автомойка, детейлинг, химчистка, шиномонтаж).
7. **Спорт** (Фитнес-клубы, бассейны, йога, единоборства).
